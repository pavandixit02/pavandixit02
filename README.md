## 🚀 Deploy on GitHub Pages

This portfolio can be hosted using GitHub Pages.

### 1. Create a GitHub repository

Create a repository such as:

```text
pavan-portfolio
```

### 2. Initialize Git

```bash
git init
```

### 3. Add files

```bash
git add .
```

### 4. Create the first commit

```bash
git commit -m "Initial portfolio website"
```

### 5. Connect the remote repository

```bash
git remote add origin https://github.com/pavandixit02/pavan-portfolio.git
```

### 6. Push the project

```bash
git branch -M main
git push -u origin main
```

### 7. Enable GitHub Pages

Go to:

```text
Repository
   ↓
Settings
   ↓
Pages
   ↓
Deploy from a branch
   ↓
main
   ↓
/
   ↓
Save
```

GitHub will then provide the published website URL.
