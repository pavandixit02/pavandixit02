## 🌐 GitHub Pages

Push the repository:

```bash
git init
git add .
git commit -m "Build portfolio website"
git branch -M main
git remote add origin https://github.com/pavandixit02/pavan-portfolio.git
git push -u origin main
```

Then configure:

```text
GitHub Repository
→ Settings
→ Pages
→ Deploy from a branch
→ main
→ /
→ Save
```

### Important GitHub Pages note

Because the requested main file is `pavan.html`, the root GitHub Pages URL may not automatically open it. The direct page URL will be:

```text
https://YOUR-USERNAME.github.io/pavan-portfolio/pavan.html
```

If you want:

```text
https://YOUR-USERNAME.github.io/pavan-portfolio/
```

to open the portfolio directly, add a small `index.html` redirect/entry file while keeping `pavan.html` as the main portfolio source.
