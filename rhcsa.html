RED HAT CERTIFICATION

RHCSA

Red Hat Certified System Administrator

What this certification validates

RHCSA validates core system-administration skills for Red Hat Enterprise Linux environments. Red Hat states that the credential is earned by passing the performance-based EX200 exam.

Official study / exam topics

  • Essential command-line tools, files, directories and documentation
  • Software/package management
  • Shell scripting fundamentals
  • Running systems, processes, services and logs
  • Partitions, LVM, file systems and storage
  • Networking, SSH and firewalld
  • Users, groups and privileged access
  • SELinux and basic security
  • Basic container management

Practical work documented in my portfolio

My portfolio documents hands-on Linux/RHEL administration practice involving users and groups, permissions, storage configuration, services, SSH, networking fundamentals and shell-based administration. These are documented as practice/lab work rather than claims that every listed activity was performed specifically during the exam.

Relevant roles / career areas

The certification is designed for system-administration work in RHEL environments and can support roles such as Linux/System Administrator, Infrastructure Support, Cloud Support and entry-level DevOps-oriented infrastructure work. The certification itself is a skills validation; a job title is not guaranteed by holding it.

Certification path

RHCSA is a foundation for progressing toward Red Hat engineering credentials. Red Hat's current 2026 framework organizes certifications by specialization; active existing credentials are mapped into the updated framework.
